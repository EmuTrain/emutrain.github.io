下载 EmuTrain ​

EmuTrain 目前支持 Android 平台。

推荐下载方式 ​

优先推荐

建议优先从 QQ 群 内下载最新版本，群内版本更新最及时，也可以直接联系开发者反馈问题。

GitHub Releases ​

GitHub 提供正式发布的版本，包含完整更新日志。

🔗 https://github.com/CrYinLang/EmuTrain/releases

Gitee Releases ​

国内用户推荐使用 Gitee，下载速度更快。

安装说明 ​

  1. 下载 .apk 文件到您的 Android 设备
  2. 在设备的文件管理器中找到下载的 APK
  3. 点击安装，系统可能提示"来自未知来源"，请允许安装
  4. 安装完成后，首次启动需阅读并同意用户协议

注意

EmuTrain 目前仅支持 Android 系统，iOS 版本暂未发布。
