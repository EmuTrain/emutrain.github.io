功能概览 ​

EmuTrain 由四个主要模块构成，通过底部导航栏切换：旅行、搜索、其他、设置。

🚄 旅行（主页） ​

旅行页面是 EmuTrain 的核心主页，用于管理和查看您的行程记录。

行程卡片 ​

有车时，主页会以卡片形式展示每段行程，包含：

  • 车次信息（如 G1 次）
  • 上下车站及时间日期
  • 站点信息（始发 → 终到）

点击卡片可进入详细信息页，查看：

  • 列车运行状态
  • 坐席类型（一等座 / 二等座 / 商务座等）
  • 乘车日期
  • 始发终到与具体站点区间
  • 点击右侧按钮可打开线路走向图

添加行程 ​

暂无行程时，点击右下角的 + 按钮即可添加新行程，支持：

  • 按车次查询并选择区间
  • 按车站查询
  • 填写坐席信息保存记录

行程管理 ​

  • 按出发时间排序
  • 支持清空所有行程（需二次确认）

🔍 搜索 ​

搜索是 EmuTrain 最强大的核心功能之一，支持两种查询方式。

车次查询 ​

输入车次号（如 G1、D301、K27）后，可查询该次列车的：

  • 完整停靠站点与到发时刻
  • 担当动车组型号与车组号
  • 重联编组信息
  • 始发终到站及运行时间

支持的数据源：

数据源特点
Rail.re第三方 API，数据更丰富，含重联与城际信息
RailGo第三方 API，数据更丰富，含重联与城际信息
12306 官方官方权威，最准确，但不显示重联与城际等信息

动车组查询（车号/交路查询） ​

输入动车组车组号（如 CRH380A-1001、CR400BF-4501）后，可查询：

  • 当日担当交路（运行的具体车次）
  • 配属路局与配属段
  • 制造厂家
  • 相关站点信息

支持的数据源：

数据源特点
Rail.re综合车型信息
RailGo综合车型信息
MoeFactory全面的车型数据库

🛠️ 其他（工具箱） ​

工具箱汇集了多项实用功能：

车站大屏 ​

选择车站，即可查看该车站目前的实时出发/到达大屏信息（仅供参考）。
数据来源：MoeFactory

线路制造处 ​

自建与管理线路图：

  • 新建线路：自定义站点、线路名称
  • 编辑线路：修改已有站点与顺序
  • 导入 JSON：从文件导入线路数据
  • 线路商店：浏览与下载社区共享线路

速度计 ​

利用 GPS 实时测量当前列车的行驶速度。

⚠️ 实验性功能，数据可能不准，仅供娱乐参考。

动车图鉴 ​

精选了一批特殊列车（特殊涂装、节日彩绘、稀有型号等）供爱好者欣赏。
数据来源：china-emu.cn

关于软件 ​

展示软件版本、数据来源与鸣谢名单，也可在此查看最新版本更新。

友情链接 ​

推荐的相关 APP 与网站：

  • 路路通 — 国铁综合出行 APP
  • 动车组查询（Rail.re） — 动车组交路查询网站
  • RailGo — 铁路信息查询 APP
  • MoeFactory 车箱 — 综合铁路数据平台
  • 动车组图鉴（china-emu.cn） — 动车组图片数据库

⚙️ 设置 ​

主题设置 ​

选项说明
深色模式手动切换深色 / 浅色主题
子夜模式深度黑色背景，护眼夜间模式
跟随系统随系统深浅色自动切换
主题色自定义颜色种子，支持 Material You 莫奈壁纸色

图标显示 ​

选项说明
显示列车图标开关搜索结果中的动车组车型图标
显示路局图标开关路局图标展示

数据源 ​

可分别为车次查询、车号/交路查询、车站查询单独指定数据源。

自动更新 ​

  • 自动检测更新：启动时自动检测新版本并弹窗提示
  • 静默更新数据库：后台自动更新本地站名、列车等数据文件

应用信息 ​

  • 点击版本号可手动检查更新
  • 点击开发者可跳转至 GitHub 与抖音主页
