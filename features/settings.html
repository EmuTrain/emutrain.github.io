⚙️ 设置 ​

设置页面让您根据个人喜好定制 EmuTrain 的外观与行为。

主题设置 ​

深浅色模式 ​

选项说明
深色模式手动切换到深色 / 浅色主题
子夜模式在深色基础上使用纯黑背景，更适合 OLED 屏幕省电
跟随系统自动随系统深浅色设置切换，优先级最高

主题色 ​

EmuTrain 支持 Material You 动态取色：

  • 默认使用设备壁纸的莫奈取色（仅支持 Android 12+）
  • 也可手动从色轮中自定义种子颜色
  • 清除自定义颜色后自动恢复莫奈取色

图标显示 ​

选项说明
显示列车图标在搜索结果中显示对应动车组车型的图标图片
显示路局图标在搜索结果中显示所属路局的 logo 图标
显示相似走向搜索线路时同时显示走向相近的其他线路

数据源设置 ​

可为三类查询分别指定数据源，按个人喜好灵活搭配：

车次查询数据源 ​

数据源描述
Rail.re（默认）第三方 API，提供更丰富的数据，但可能缺少部分数据
RailGo第三方 API，提供更丰富的数据，但可能缺少部分数据
12306 官方官方数据源，最准确可靠，但不显示重连、城际等

车号 / 交路查询数据源 ​

数据源描述
Rail.re（默认）综合车型信息与交路数据
RailGo综合车型信息与交路数据
MoeFactory全面的车型信息，第三方数据源

车站查询数据源 ​

数据源描述
MoeFactory（默认）提供详细的车站时刻与席别信息
携程备选数据源

自动更新 ​

选项说明
自动检测更新应用启动时自动检测新版本，有更新时弹窗提示
静默更新数据库后台自动下载最新的站名、列车型号等本地数据文件

数据镜像源 ​

由于某些地区访问 GitHub 可能较慢，EmuTrain 提供三个镜像源选项：

镜像源地址
Mirror（默认）https://gh-proxy.com/... GitHub 加速镜像
Giteehttps://raw.giteeusercontent.com/CrYinLang/EmuTrain/...
GitHubhttps://raw.githubusercontent.com/CrYinLang/EmuTrain/...

切换镜像源后，下次拉取数据时生效。
建议国内用户优先使用 Mirror 或 Gitee。
