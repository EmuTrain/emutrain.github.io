On this page

🛠️ 工具箱 ​

工具箱汇集了 EmuTrain 中的各类实用辅助功能，满足铁路爱好者的多样需求。

车站大屏 ​

模拟查看全国各大车站的实时出发 / 到达信息大屏。

  • 进入后选择目标车站
  • 显示该站近期的列车时刻与轨道信息
  • 界面类似车站现场的候车大屏

⚠️ 数据仅供参考，以实际车站大屏为准
数据来源：rail.moefactory.com

线路制造处 ​

自定义创建和管理您的专属线路图。

主要功能 ​

功能说明
新建线路自定义名称、添加站点、设置线路颜色
编辑线路修改已有线路的站点与顺序
浏览线路以列表形式管理所有保存的线路
搜索线路在已保存线路中搜索
导入 JSON从 JSON 文件导入线路数据
批量操作批量选择并删除线路

线路商店 ​

线路商店提供由社区共享的线路文件，可以一键下载并导入到本地使用，方便快速获取热门线路的站点数据。

GPS 速度计 ​

利用设备 GPS 实时测量当前行进速度，适合在乘车途中感受速度变化。

  • 显示实时GPS 测速（km/h）
  • 适合铁路爱好者在高铁 / 动车上记录速度峰值

实验性功能

GPS 速度计为实验性功能，数据精度受 GPS 信号质量影响，可能不准，仅供娱乐参考，请勿用于安全相关判断。

动车图鉴 ​

精选了一批特殊涂装、节日彩绘、限定涂装等稀有列车的图片，共铁路爱好者欣赏与收藏。

  • 覆盖 CRH、CR 等各系列动车组
  • 包含节日/纪念涂装、广告涂装等特殊车辆
  • 支持浏览完整图鉴列表

完整图鉴来源：china-emu.cn/Trains/ALL
