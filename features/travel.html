🚄 旅行记录 ​

旅行页是 EmuTrain 的主页，也是最核心的功能之一。它让您把每一次乘火车的经历完整留存下来。

主页行程卡片 ​

当您有已添加的行程时，主页会以卡片形式列出它们，每张卡片展示：

  • 🚂 车次号（如 G1、D301、K27）
  • 🏁 上车站 → 下车站
  • 🕐 出发时间 与 到达时间
  • 📅 乘车日期

提示

列车图标与路局图标可在设置 → 图标显示中开关。

行程详情 ​

点击任意行程卡片，进入详情页，可查看：

  • 列车当前运行状态
  • 坐席类型（商务座 / 一等座 / 二等座 / 软卧 / 硬卧 / 硬座等）
  • 乘车日期
  • 始发终到站与所选区间
  • 完整停靠站点列表

点击右侧的线路图按钮，可查看整条线路的走向图，包含所有停靠站点、到发时刻与里程信息。

添加行程 ​

在主页右下角点击 ＋ 按钮，即可添加新行程：

  1. 输入车次（如 G1）
  2. 从查询结果中选择上车站与下车站
  3. 选择乘车日期
  4. 填写坐席信息
  5. 点击保存

支持自定义行程，手动填写各项信息，适用于普速列车或特殊情况。

管理行程 ​

在主页右上角菜单中可进行：

操作说明
按日期排序将所有行程按出发时间从早到晚重新排列
清空所有删除全部行程（需二次确认，操作不可撤销）

线路走向图 ​

在行程详情页点击右侧按钮，可打开线路走向图：

  • 以列表或图形方式显示该车次全程停靠站点
  • 标注每站的到达 / 出发时刻
  • 支持显示里程估算（在设置中开启）
  • 高亮您的上车站 → 下车站区间

数据来源：rail.moefactory.com
